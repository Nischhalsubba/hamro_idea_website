# Merge Request Description

## Title
Merge develop into main: full site refresh, navigation unification, and styleguide system

## Executive Summary
This merge brings the latest develop branch into main. The work focuses on a full content and layout refresh across the marketing site, cohesive mega menu navigation, improved micro-interactions, and a world-class design system. The merge also introduces a complete multi-format styleguide (HTML, print/PDF, and Markdown) and a deeply structured README to support onboarding and governance.

The objective of the merge is not only to update visuals and content, but to standardize the experience across all pages and ensure the site meets technical, SEO, and accessibility expectations. This description provides a deep, comprehensive record of what changed and how it aligns to the product and brand goals.



---

## Scope of Changes

The scope covers all major site areas:

- Core navigation and mega menu architecture
- All primary and detail pages connected from navigation
- Content audit and rewrite for SEO and technical credibility
- Interaction patterns: reveal animations, page spinner, back-to-top
- Global visual polish, including subtle noise texture and contrast fixes
- Full design system and documentation coverage

This merge consolidates all of the above into a single, consistent experience for the brand.



---

## Information Architecture Impact

The navigation is the backbone of the site. The develop branch standardizes the mega menu system across all primary nav items to ensure the user’s experience is consistent regardless of where they enter. Every menu item resolves to a real, content-rich page. The architectural changes prioritize clarity and a seamless path to service discovery.

The key goals were:

- Ensure every navigation item has a real destination page.
- Ensure every major service area is reachable from the mega menu.
- Provide cross-links between relevant sections for improved discoverability.
- Maintain a premium visual language without sacrificing usability.
