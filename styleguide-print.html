1. Overview + Operating Rules

Consistency creates trust, clarity, conversion, and speed across every page.

Purpose

Premium credibility and technical confidence for companies and founders with ambitious ideas.

Scope

Marketing website: Home, Services, Solutions, Work, Process, About, Insights, Contact, Legal, 404/500.

Audience

Design, engineering, content, SEO, QA, and stakeholders.

Principles

Clarity over clever. One primary action per section. Performance first. Trust over noise.

Source of truth: CSS in assets/css/main.css, HTML templates in templates/main.html, components in organisms/.

2. Brand Foundations

Logo, color intent, typography, imagery, iconography, and motion identity.

Logo System

Primary logo, icon mark, and favicon. Keep clear space equal to the logo icon width. Minimum size: 120px wide for header.

Color Intent

Navy anchors credibility, indigo drives action, magenta highlights premium details, gold signals priority.

Typography Identity

Manrope is the only brand typeface. Clean, modern, technical.

Imagery Direction

High-contrast, crisp UI/product visuals, minimal clutter, generous negative space.

Iconography

Simple geometric icons, consistent stroke, used to guide navigation and scanability.

Motion Tone

Confident and subtle. Motion clarifies hierarchy and interaction feedback.

5. Texture + Atmosphere

Subtle noise overlays add depth without breaking readability.

  • Global noise overlay: body::before (fixed, full-page).
  • Section noise wash: section::before for local texture.
  • Mix-blend-mode: overlay + soft-light for subtle grain.

Noise overlay is defined in assets/css/main.css.

Reduced Motion

9. Component Library

Every component has documented anatomy, variants, states, and behavior.

Component Spec Template

  • Purpose + when to use
  • Anatomy (named parts)

State Coverage Standard

Every interactive component must ship with visible focus, hover, pressed, and disabled states. Loading state is mandatory for forms and primary CTAs.

Content Rules

CTAs use verb + outcome. Labels stay under 24 characters. Titles stay under 60 characters. Support text stays under 140 characters.

12. Accessibility Standards

Website-ready standards mapped to WCAG 2.2 expectations.

Keyboard Navigation

Logical tab order, skip-to-content link, focus never trapped. All menus accessible via keyboard.

Focus + Contrast

Visible focus ring on all interactive elements. Text contrast meets AA for body and UI labels.

Forms + Errors

Visible labels, helper text when needed, error message connected to input, success confirmation.

Media + Motion

Meaningful alt text for content images. Reduced motion disables animated effects.

14. SEO Standards

Search-ready copy, metadata, and internal linking rules.

Title + Meta

Title format: Primary keyword + brand. Meta description 140-160 chars with clear outcome.

Heading Structure

One H1. H2s for sections, H3s for sub-points. Headings include location + service.

Internal Linking

Every page links to a related service, a proof element, and a conversion page.

15. Performance + Media

Optimization rules that protect Core Web Vitals and UX.

Images

Use SVG for icons. Use modern formats for photos. Always set width/height to prevent layout shift.

Fonts

Limit to 2-3 weights. Use font-display: swap. Avoid unused weights.

Video + Motion

Hero video only when essential. Provide poster image. Avoid heavy scroll-based effects.

JS + CSS

Prefer CSS for animations. Keep JS lightweight and defer non-critical scripts.

18. Engineering Implementation

Design-to-code contract, naming conventions, and delivery rules.

Token Strategy

Global tokens map to semantic intent (text.primary, bg.surface). Component tokens override locally.

Naming Conventions

Use BEM-style blocks where appropriate. Avoid deep nesting and over-specific selectors.

Component Rules

All components ship with full states and accessibility defaults. No custom inline styles on pages.

Performance Rules

Images optimized, scripts deferred, and CSS audited for unused selectors.
